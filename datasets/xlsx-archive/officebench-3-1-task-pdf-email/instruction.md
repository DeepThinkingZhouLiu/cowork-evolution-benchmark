# Convert a project task sheet to PDF and email it

Read `task_input.xlsx`, which contains a project task table. Create `/app/output/task.pdf` as a readable PDF conversion of the table, preserving every task row and its visible task name.

Create `/app/output/Alice.eml` as an email draft addressed to Alice. Attach the generated `task.pdf` to the message. The email should identify the PDF as the project task sheet and be suitable for sending for review. Keep the PDF and the attachment filename aligned; do not use a screenshot in place of the PDF or omit any source task.
