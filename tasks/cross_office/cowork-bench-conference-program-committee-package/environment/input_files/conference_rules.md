# ДРВБ-2026：冻结的会议规则

- 会议全名：`Древняя Русь и Волжская Булгария: история и археология. Памяти А.П. Смирнова`。
- 日期：2026-03-17 至 2026-03-19。
- 场地：Казанский федеральный университет (КФУ)，Институт международных отношений。
- 录用规则：三位审稿人平均分大于或等于 4.0 时录用，否则拒绝；平均分按两位小数展示。
- `Археология`：2026-03-17，10:00–13:00。
- `Источниковедение`：2026-03-18，10:00–13:00。
- `История`：2026-03-19，10:00–13:00。
- 每个分会场必须安排 2–4 个报告；每个报告 30 分钟，按 10:00、10:30、11:00……顺序排期，不允许重叠。
- 录用通知主题：`Ваш доклад принят на ДРВБ-2026`，正文必须包含报告题目、分会场、日期和时间。
- 拒稿通知主题：`Решение по заявке ДРВБ-2026`，正文只需礼貌说明拒绝，不得泄露审稿人分数、其他作者信息或内部比较排名。
- 所有对作者的通信使用俄语，并提及 `ДРВБ-2026` 与会议日期 `17–19 марта 2026`。

本文件将上游 forms、Teamly 和任务说明中的固定状态物化为离线规则，不新增会议、作者、论文或评审事实。
