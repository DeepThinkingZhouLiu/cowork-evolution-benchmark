# 核对并修正董事会收入口径

你是财务 BP。三个文件对 7 月收入表述冲突，请按口径规则确定权威实际、解释差异，并提供可审计核对表与董事会修正说明。

## 输入文件

- `finance_actual.csv`
- `sales_forecast.xlsx`
- `board_draft.docx`
- `口径规则.json`

## 交付要求

- 明确 1,280,000 元是权威已确认收入。
- 解释 1,350,000 元预测与 70,000 元未验收差异。
- 核对表保留来源、用途和修正记录。
- Word 给出董事会材料的准确替换表述。

## 输出位置

- `/app/output/收入口径核对.xlsx`
- `/app/output/董事会口径差异说明.docx`

不得联网。多个交付物中的同一数字、日期、责任人和结论必须完全一致；不得把输入材料中没有出现的内容写成事实。
