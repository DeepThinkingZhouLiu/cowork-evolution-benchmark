# 收入门槛筛选交付包

本题将 2004–2023 年收入源表转换为可重算的 Excel 审计工作簿和事实一致的 Word 管理报告，用 200 万美元的含等号门槛划分保留与移除年份。

- `rubric.v1.json`、`tests/judge_v1.py` 和 `tests/negative_cases_v1.py` 完整保留首版全或无评分。
- 默认 v2 对 20 年来源数据、17 个保留年、3 个移除年、原生公式、12 项汇总、Word 表格事实和跨文件一致性逐项计分。
- 核心交付缺失、为空、损坏、无法解析或只交回输入时才硬归零；局部事实或公式错误保留连续部分分。
- 本题只交付 XLSX 和 DOCX，不适用 VLM 评分；LibreOffice 只用于公式重算与可渲染性检查。
- 可用 `SCORING_VERSION=v1` 回放旧版，默认使用 `v2`。

v2 已验证 Golden 和两次空目录重放均为 1.0，空交付和只交回输入均为 0；61 个分层负例包含 8 个硬失败和 53 个连续部分分案例。
