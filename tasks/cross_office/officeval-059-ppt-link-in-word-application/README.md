# Word 申报书链接 PPT 交付包

本题要求在四页 Word 项目申报书的指定表格单元格内建立指向同目录 18 页 PPT 的真实相对超链接，同时原样交付该 PPT，并保持原 Word 的文字、表格、边框、页眉和页码。

- `rubric.v1.json` 与 `tests/judge_v1.py` 完整保留首版全或无评分；设置 `SCORING_VERSION=v1` 可显式回放。
- 默认 v2 按 PPT 的 18 页内容与媒体、目标行与显示文字、OOXML 关系、链接样式、Word 包成员保留、四页渲染和表格结构连续计分。
- 只有核心 DOCX/PPTX 缺失、为空、损坏/不可解析，或把未修改的输入 Word 改名交回时硬归零；局部链接、格式、保真或版式错误保留部分分。
- 随附 PPT 采用专属 reference-mode 视觉 Rubric，并与确定性分按 `70% + 30%` 汇总；Word 超链接语义仍由确定性 Judge 检查。

v2 已验证 Golden 和两次 fresh replay 均为 1.0，空交付与原样输入均为 0；30 个任务专属分层负例中有 8 个硬 0 和 22 个连续部分分案例。
