# 区域汇报链接 CRM 工作簿交付包

本题要求在十页区域经营汇报的第 8 页右侧空白区新增一个可点击的 Excel 工作簿按钮，同时原样交付三工作表 CRM Pipeline 文件，并保持原 PPT 的页面、对象和内容不变。

- `rubric.v1.json` 与 `tests/judge_v1.py` 完整保留首版全或无评分；设置 `SCORING_VERSION=v1` 可显式回放。
- 默认 v2 按三张工作表保真、按钮语义、九项几何边界、OOXML 链接关系、十页原稿保留、真实渲染、可编辑样式和安全边界连续计分。
- 只有核心 PPTX/XLSX 缺失、为空、损坏/不可解析，或把未修改的输入 PPT 改名交回时硬归零；局部链接、样式、位置或保真错误保留部分分。
- 第 8 页采用专属 reference-mode 视觉 Rubric，并与确定性分按 `70% + 30%` 汇总；工作簿内容与形状级链接语义仍由代码逐项检查。

v2 已验证 Golden 和两次 fresh replay 均为 1.0，空交付与原样输入均为 0；33 个任务专属分层负例中有 8 个硬 0 和 25 个连续部分分案例。
