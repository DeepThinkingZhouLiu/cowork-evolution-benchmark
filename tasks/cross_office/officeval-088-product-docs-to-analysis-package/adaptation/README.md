## 真实标准答案是怎么来的

- 五行名称、型号、价格、参数和场景逐份来自对应 Word；价格排序为云溪 4500 元、统帅 3999 元、小天鹅 3039 元、米家 999 元、美的 846 元。
- Word 只选取前三个高价产品，并与 Excel 使用相同事实文本。三块从原模板一张三行表拆为三张视觉等价的一行表，使每个产品成为独立、不可跨页的语义块。
- `solution/solve.py` 只重放这一个真实任务。固定坐标是逐张看图后确定的裁剪边界，固定事实是逐份读文档后的转录，不是通用产品生成器。

## 上游规则中的边界问题

- 上游文字 Rubric 描述了“型号”独立列，但真实 Excel 模板只有“产品名称、核心参数、适用场景、指导价格、展示图”五列。改造保留五列，把型号放在核心参数首项；上游 Verifier 也支持这种落盘方式。
- 小天鹅原文支持高温除菌和母婴使用，但不是三桶设备。Golden 写成“按批次进行外衣、内衣与宝宝衣物分类洗”，没有虚构同时分桶能力。
- 统帅原文是 UV 紫外除菌，不是“高温除菌”。Golden 只写“母婴家庭除菌衣物清洁”，不为了命中表述而捏造高温能力。
- 上游图片检查把本机没有安装 Tesseract 视为图片不通过，因此本机上游得分为 `35/50`；其余 15 分恰好是五个 OCR 检查。图片锚点、高度、显示比例和像素比例均逐项正确；本任务 Docker 已安装中英文 Tesseract，本项目 Judge 还会做来源裁剪相似度检查。
