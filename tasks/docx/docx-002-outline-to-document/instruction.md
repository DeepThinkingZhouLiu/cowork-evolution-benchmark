# 把大纲扩写成新员工入职手册

你是 People Operations 专员。公司只有一份章节大纲和结构化制度事实，需要形成一份新人拿到即可使用的手册。

## 输入文件

- `onboarding_outline.md`
- `company_policies.json`

## 交付要求

- 保留大纲的五个一级章节并补成完整内容。
- 所有时间、期限和联系方式严格以 JSON 为准。
- 30/60/90 天目标使用表格表达。
- 语气友好、明确，不编造福利或制度。

## 输出位置

- `/app/output/新员工入职手册.docx`

不得联网，不得把来源材料中没有出现的数字写成事实。交付文件必须可编辑并可由 Word 或 LibreOffice 正常打开。
