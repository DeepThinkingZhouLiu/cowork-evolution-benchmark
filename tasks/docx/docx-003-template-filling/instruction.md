# 完成供应商评审结论

你是采购风控专员，需要使用既有模板出具供应商评审结论。模板占位符必须全部替换，不能改变章节顺序。

## 输入文件

- `供应商评审模板.docx`
- `vendor_facts.json`
- `sla.csv`

## 交付要求

- 填入供应商、服务范围、合同金额、结论和生效日期。
- 把三项 SLA 做成清楚表格。
- 明确写出有条件通过的前置条件。
- 不得残留任何双花括号占位符。

## 输出位置

- `/app/output/供应商评审结论_明川云.docx`

不得联网，不得把来源材料中没有出现的数字写成事实。交付文件必须可编辑并可由 Word 或 LibreOffice 正常打开。
