# 合并两个差旅政策版本

你是公司治理专员。v2 是最新政策，但管理层还需要明确知道它相对 v1 改了什么。请同时交付一份干净合并版和一份差异说明。

## 输入文件

- `差旅政策_v1.docx`
- `差旅政策_v2.docx`

## 交付要求

- 合并版以 v2 的最新值为准，章节完整。
- 差异说明用表格逐项列出住宿、交通、审批和新增披露变化。
- 两个文件中的最新政策数字必须一致。
- 差异说明保留 v1 的旧值，合并版不得混入旧值。

## 输出位置

- `/app/output/差旅政策_合并版.docx`
- `/app/output/差旅政策_版本差异.docx`

不得联网，不得把来源材料中没有出现的数字写成事实。交付文件必须可编辑并可由 Word 或 LibreOffice 正常打开。
