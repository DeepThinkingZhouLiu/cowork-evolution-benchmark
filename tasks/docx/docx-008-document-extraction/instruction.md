# 生成付款审核摘要

你是财务共享中心审核员。请联合发票 PDF、验收记录和采购单核对供应商、服务、金额、编号和日期，并形成一份可归档的付款审核摘要。

## 输入文件

- `invoice.pdf`
- `acceptance_record.txt`
- `purchase_order.csv`

## 交付要求

- 用表格呈现单据核对结果。
- 准确写出三个单据编号、含税总额和付款到期日。
- 区分验收已通过与仍需补交录像索引两个事实。
- 给出明确付款建议和后续跟踪责任。

## 输出位置

- `/app/output/付款审核摘要.docx`

不得联网，不得把来源材料中没有出现的数字写成事实。交付文件必须可编辑并可由 Word 或 LibreOffice 正常打开。
