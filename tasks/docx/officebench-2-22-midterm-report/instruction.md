# officebench-2-22-midterm-report

## Original OfficeBench request

> Generate a word report based on midterm1 and midterm2 scores, the filename is 'midterm_report.docx'.

## Delivery requirements

Complete the request using the visible inputs and deliver only the editable DOCX file(s) `/app/output/midterm_report.docx`. The fixed output path is an offline Harbor adaptation. Preserve the source facts, ordering, and requested Word content; do not create non-DOCX deliverables.

## Task-specific details

Compute the valid student count and the Midterm 1 and Midterm 2 averages from `score.xlsx`, rounding averages to two decimal places. Include the signed difference `Midterm 2 - Midterm 1` and a short descriptive observation that does not claim causation. Present the metrics in a native editable Word table in `/app/output/midterm_report.docx`.
