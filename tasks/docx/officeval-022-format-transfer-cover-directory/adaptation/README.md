## 上游 Query 的可证实矛盾

- Query 字面称“按企业经营情况说明书的格式修改企业经营异常核查呈报材料”，但封面是华中项目，另一材料却是青月项目，两者事实无法合并。
- 上游指定输出名为 `企业经营情况说明书_按模板格式添加封面目录.docx`，六个强制一级标题也与 `企业经营情况说明书.docx` 完全对应。
- 因此本任务保留原始 Query，同时明确把 `企业经营情况说明书.docx` 作为内容主体、把另一份材料作为核查材料组织方式对照；这是由真实资产与上游评测契约共同证明的角色纠正，不是本项目新编需求。

## 真实标准答案是怎么来的

- 第一份交付保留华中说明书原文、4 张原始表和唯一资金流转图；封面逐项抄取封面输入，目录的 6 个页码按最终 LibreOffice 实际分页逐项核对为 3、4、4、5、6、7。
- 第一份把 6 个原一级标题逐一改成“第一部分：”到“第六部分：”，把 3 个括号小标题逐一改成“一、二、三、”；表格逐张改为三线表并保留真实数据。
- 第二份保留源报告全部事实与 3 张表，只替换指定长主题；8 个一级标题、14 个二级标题、正文公司名和末尾签名逐段设置，没有删改业务事实。
- `solution/solve.py` 只重放这一道真实任务。里面的标题、事实和格式参数都对应本题四份输入和上游规则，不是通用 Word 造题器。

## 版式回放中发现并修复的问题

- 第一版为了让每个一级标题独立起页，产生了 1 行孤页和大面积空白；最终取消不必要的强制分页，目录按真实页码重新核对，第一份稳定渲染为 7 页 A4。
- 第二份源文件带有 31.2 磅文档网格；如果只设置“1.5 倍行距”，LibreOffice 仍渲染为接近三倍行距。最终逐段关闭网格吸附，使 12 磅正文真正按 1.5 倍显示，页数从 11 页降为 7 页。
- 第一份封面、目录、正文 5 页和第二份 7 页均逐页视觉检查；没有空页、表格截断、整页截图或不可编辑替代物。
