# 改造说明

本题逐题改造自 OmegaUse-OfficeVal officeval_033。原 Query、66 页家居价目册、Rubric、Verifier 和许可证均原样保留。

我逐表读取了来源 DOCX，并确认需要修改的是五类表：206 个组合规格价、153 个推荐配套价、1057 个定制价、8 个换算提醒价和 11 个门店订购价，共 1435 个零售价单元格。料号、尺寸、数量、比例和其他数字不属于目标。

Golden 使用 Decimal 的 ROUND_HALF_UP 规则计算 1.1 倍整数；只改 word/document.xml 中这 1435 个文本节点，其他包成员逐字节复制。solve.py 固定校验本题输入 SHA256、表类型和单元格计数，不是无差别数字乘法器。

Judge 逐个将输出价格与来源价格对照，同时逐字比较所有非目标文本、逐字节比较其他包成员、调用上游抽样 Verifier，并实际渲染 66 页 PDF。
