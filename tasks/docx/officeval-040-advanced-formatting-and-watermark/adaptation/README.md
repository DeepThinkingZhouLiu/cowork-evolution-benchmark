# 改造说明

本题逐题改造自 OmegaUse-OfficeVal officeval_040。原 Query、两个真实输入、Rubric、Verifier 与许可证原样保留。

我逐段读取了 11 段来源正文。为了同时满足“第三段”和“专业设置如下：”的明确要求，Golden 不删改任何文字，而是把原第三段中此前的介绍句并入第二段，把“专业设置如下：”作为第三个可见段，并采用 Word 的首字段加其余文字段结构实现真实悬挂首字下沉。

水印只使用来源校园横幅。考虑到 LibreOffice 不执行 Word 的 VML `o:gain/o:blacklevel` 冲蚀滤镜，Golden 同时把来源像素与白色按 22%/78% 确定性混合，再补充 240 DPI 元数据；这样 Word 仍有原生冲蚀属性，LibreOffice 也不会用过实的背景压住正文。Judge 从输入图独立重算同一冲蚀结果并逐像素比较，确认没有替换成其他图片。

solve.py 固定校验本题两个输入的 SHA256，逐段设置标题、正文、特殊名称、首字下沉和 VML 图片水印；它不是通用 Word 格式转换器。
