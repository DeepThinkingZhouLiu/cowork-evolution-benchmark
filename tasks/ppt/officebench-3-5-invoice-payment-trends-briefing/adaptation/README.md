## 视觉评分适配（visual-v1）

- 模型逐题读取了任务指令、`task.toml`、确定性 Rubric、完整 Judge、期望用例、上游 Query、来源/哈希与许可；两份单页 PDF 均提取全文并查看原尺寸页面，确认其同为 `Invoice #100`，但日期、客户、业务、物流和付款对象不同。
- Golden 的原生表格、堆积图和全部文本已展开检查；5 页先以 2 列接触表查看，再逐页查看 1920×1080 原图。页面依次为冲突概览、十一列发票登记、金额构成、条款与状态边界、四项复核行动。
- 本题允许不同的财务汇报主题、图表和页面组织，属于开放式材料到简报任务，因此采用 `reference_free`；Golden 只参与 Rubric 制定和稳定性校准，不要求候选复制版式。
- `V001` 检查总额和编号冲突的封面层级，`V002` 检查十一列两行登记表与来源卡，`V003` 检查金额差异很大时堆积图的分段可读性，`V004` 检查 Terms 与 Payment status 的视觉边界，`V005` 检查四项控制行动与 Known/Unknown 收口，`V006` 检查五页叙事及四色语义系统；事实和可编辑性仍由确定性 Judge 判定。
