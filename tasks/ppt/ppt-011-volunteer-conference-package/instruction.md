# 志愿者大会演示交付包

## 业务背景

你是公益行业的会务项目经理。请基于提供的文件完成一份可在真实办公场景中直接交付的演示成果。本题禁止联网，所有可使用信息都在输入文件中。

## 输入文件

- `年度志愿者大会素材.docx`
- `参会数据.xlsx`
- `会务信息.md`
- `大会主视觉.png`

## 任务要求

- 交付PPTX主稿、PDF参会手册和DOCX讲者手册三个文件
- 三个文件的主题、日期、地点、时间与核心数据必须一致
- 不得在任何交付物中暴露志愿者个人手机或地址

- 每页必须有可单独理解的标题，结论、证据与行动不得互相矛盾。
- 交付物中的文字、表格、图表和图片必须可编辑、可打开且无遮挡溢出。
- 不得把 `solution/`、`tests/` 或 Rubric 内容复制进交付物。

## 交付文件

将以下文件保存到 `/app/output/`：

- `2026微光志愿者大会.pptx`（PPTX）
- `2026微光志愿者大会_参会手册.pdf`（PDF）
- `2026微光志愿者大会_讲者手册.docx`（DOCX）

不要更改文件名，不要另行打包 ZIP。
