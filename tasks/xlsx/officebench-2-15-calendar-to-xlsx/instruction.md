# Convert a calendar agenda to Excel

Read `Alice.ics` in the input folder. Create `/app/output/meeting_agenda.xlsx` for further analysis.

The workbook must contain a sheet named `Meeting agenda`. Keep the agenda title and a clear table with these columns: `Start`, `End`, `Time`, `Item`, and `Contact`. Transcribe every meeting from the calendar, sort the rows by start time, and keep the original meeting names, contacts, start/end times, and durations. Use native editable Excel cells with readable time formats; do not submit a screenshot or a pasted image.

Do not add meetings that are not in the calendar. The output directory should contain the requested workbook.
