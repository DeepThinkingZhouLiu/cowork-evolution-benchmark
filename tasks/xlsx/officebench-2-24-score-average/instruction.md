# Extract scores and calculate an average

Read `score_input.xlsx`. Create `/app/output/score.xlsx` as an editable Excel workbook.

Keep a table with the original `Name` and `Score` columns and preserve every source row and value. Add one final row labeled `Average` in the Name column and put the arithmetic mean of all source scores in the Score column. Use a numeric cell and a readable number format for the average. Do not add or remove students, and do not submit a screenshot or a text-only answer.
