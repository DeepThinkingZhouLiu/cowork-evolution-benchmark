# 筛选公司收入并整理摘要

请读取输入文件 `company_revenues.xlsx`，创建一个可继续编辑的 Excel 工作簿并保存为 `/app/output/Revenue_Filter.xlsx`。

工作簿必须包含以下三个工作表，且按此顺序排列：

- `Filtered Revenue`：删除收入低于 `$2,000,000` 的年份，保留其余年份及原始收入和输入顺序。阈值恰好等于 `$2,000,000` 时应保留该行。
- `Filter Summary`：用 `Metric, Value` 两列说明筛选阈值、筛选前行数、保留行数和删除行数。
- `Deleted Records`：列出被删除的年份及对应原始收入。

保留原列名和原始收入数值，不要重排或改写收入。三个工作表应使用原生可编辑单元格，并设置清晰表头、合理列宽和筛选/冻结首行。
