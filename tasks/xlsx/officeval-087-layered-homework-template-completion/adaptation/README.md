## 真实标准答案是怎么来的

- 标题、简介、基础层、提高层、拓展层和反馈内容都从源工作簿对应单元格逐项阅读后迁入，不新增题目或知识点。
- 8 个输出媒体对象全部直接复用源 XLSX 中的原始二进制：基础层选取 6 个田字格，提高层选取源表实际使用的两张山水图；Judge 对媒体 SHA256 多重集合逐项比对。
- 输出的三工作表结构、8 个合并区域、边框和填充来自目标模板，而不是本项目重新设计的表格。

## CoworkEvoBench 改造决策

- 原始 Query 逐字保留，只增加两个输入文件名、固定输出路径、禁止整表截图和模板保护边界。
- 只迁入作业正文，不把源表答案区复制到学生作业模板；这是由目标模板职责和原始 Query 的“粘到分层设计表格”共同确定的边界。
- 为避免图片覆盖题干，逐张设置锚点和尺寸；打印设置改为横向单页宽、纵向 3 页，表格不再像原模板那样横向拆成两份。
- `solution/solve.py` 只处理这两个固定真实工作簿，文本和媒体名称都经过逐题核对，不是可替换输入的批量制题脚本。
