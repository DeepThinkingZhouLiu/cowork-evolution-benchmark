# 完成并购估值、协同和财务报表联动

打开 `16_02_input.xlsx`，在不改变现有结构、布局、格式和已填数据的前提下完成并购模型：

1. `Valuation Summary`：用 Gordon Growth Model 计算 Terminal Value；汇总折现现金流计算 Present Value of FCFF；对含收购流出和终值的完整现金流序列计算 Implied IRR；用 EBITDA 法完成 Enterprise Value。
2. `Synergies and Intgn Exp`：汇总各欧洲岗位成本，计算 2023E-2027E 的 Total Europe New Headcount。
3. `Income Statement`：计算 2019A-2027E 的 EBITDA 和 Retained Earnings。

所有新增结果必须使用可重算公式。将唯一交付文件保存为 `/app/output/ma_valuation_16_02_completed.xlsx`。
