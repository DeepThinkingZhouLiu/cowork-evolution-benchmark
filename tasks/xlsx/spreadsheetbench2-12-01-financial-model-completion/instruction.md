# 完成财务模型中的预测公式

请打开 `financial_model_input.xlsx`，在不改变既有工作表结构、布局、格式和已填数据的前提下完成以下公式：

1. `Assumption`：用 Y-o-Y Growth 假设计算 FY26E–FY30E 的 Revenue，并用 Total Revenue 百分比假设计算同期 COGS。
2. `Working Capital`：用 Receivable Days=70 计算 Mar-26–Mar-30 的 Receivable，并从 FY25A 到 Terminal Value 逐期计算 Changes in Working Capital。
3. `P&L`：计算 FY20–FY30E 的 EBITDA Margin %。

所有新增结果必须是可重算的 Excel 公式，不要硬编码结果；除上述目标单元格外保留原工作簿。将完成文件保存为 `/app/output/financial_model_completed.xlsx`。
