## 源证据与新任务

2024 四月 13 笔行政支出 21089 元，原预算 25050 元；2025 预算实际有 35 个叶子科目，单位万元，物业与保洁年度原格为空但月度有值，大类合计不能再加一次。2022 年五笔备用金与 2024 年五月左右并列表不能当同月流水。2024 表左右各 16 笔，五月1至15日存入62423.2、支出8293.4、净额54129.8；展示余额54168.8却使用全范围，差39正是区间外收支净额。

据此逐题设计七页签：明细底稿、年度/月度单位转换、跨期现金账、预算情景和证据审查。交通与差旅共用预算仅为题面明确的分析假设，不冒充上游政策；不可映射项保留未知。所有关键结果原生公式，动态测试改变金额/期间外记录后重排底稿，检查按科目关联而非死抄数字。

Judge独立读取冻结原文件，不读取Golden，不共享参考解计算。部分正确分别给分，不增加VLM。初次反例测试发现纯抄数可获过高行为分，正式版本去掉不变数字的行为奖励，并把权重从抄底稿调整到计算与联动；没有参考真实Agent分数调整难度或阈值。
