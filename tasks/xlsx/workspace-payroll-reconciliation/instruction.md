# 薪酬版本核对与可重算预算审查

你是向 HR 交接薪酬底稿的财务分析师。输入目录 /app/data/input_files/ 中有年度薪酬表、两份月度表和一份分析报告，它们不是同一统计范围，不能选择一个数字覆盖其余版本。唯一交付文件 /app/output/payroll_review.xlsx 必须包含以下工作表。金额为元，人数与比例使用数值单元格，保留来源定位。

1. 年度底稿：按原工作表顺序保留两张表的全部年度明细，不含合计行。A:G 为版本、年份、人数、年度薪酬、业绩、原列月均人均薪酬、来源定位。两张表分别标记 A、B。来源写原文件名、sheet 和原始行号。不得按同年去重。
2. 月度底稿：保留两个工作簿各两张表的全部部门明细，不含合计行。按文件3、4及原sheet顺序排列。A:E 为版本、部门、人数、工资、来源定位；版本依次为 图A、图B、明细A、明细B。不能把图表和明细重复计入同一汇总。
3. 报告底稿：A:D 为指标、原文数值、单位、来源章节。第2—5行依次为 报告人数、报告月总额、报告月均薪酬、学习基金每人年额。报告数不得替换工作簿底稿。
4. 职级情景：A:G 为职级、人数、原月薪、假设涨幅、原月成本、新月成本、月增量；第2—5行按报告初级、中级、高级、专家顺序，人数、原月薪来自职级表。仅作为情景假设，将报告中层累计涨幅用于中级，将高层一次性涨幅用于专家，其余涨幅为0。E:G必须是引用本表参数的公式。这是假设映射，不代表已批准方案。
5. 核对指标：A:C 为指标、计算结果、来源/口径。第2—14行按顺序计算：A版2021至2024薪酬合计、A版同期原列人均薪酬算术均值、图A人数、图B人数、图A工资、图B工资、B减A人数差、报告月总额除人数、报告公布均薪减重算均薪、职级表月成本合计、职级月成本减报告月总额、情景年度新增工资、报告口径年度学习基金。B列必须引用底稿/情景表计算，不能抄常数。年度情景按参数不变的12个月测算，学习基金不混入新增工资。
6. 部门核对：A:F 为部门、A版人数差(图减明细)、A版工资差、B版人数差、B版工资差、B减A人数差；七部门按名称关联，不按位置碰巧相减。B:F使用底稿引用公式，可以在右侧加图表数据。
7. 审查结论：A:E 为问题、证据定位、数值依据、判断、后续核验动作。至少逐项处理：年度两版本不能并表；月度人数版本差异及各版本图表/明细核对；年度与报告期间和人员范围不同，不能宣称增长率；报告公布均薪与总额除人数的差额；职级表汇总月成本与报告总额冲突。不能把待确认写成已更正，不得创造员工名单、批准日期或实际调薪支出。另行说明职级情景的假设映射。

至少内嵌一张可编辑的部门工资对比图，引用工作簿数据。各表有表头、筛选、冻结首行和清晰数值格式，启用自动重算，无外部链接。修改底稿数值或情景涨幅后下游必须更新。保留所有输入原文件。不输出PDF/PPT或图片替代物，不联网。
